# Raw Data

Эта папка зарезервирована для локальных исходных материалов.

Не рекомендуется публиковать полные тексты пользовательских отзывов без дополнительной проверки прав и условий площадок. Для публичного GitHub-деплоя достаточно хранить в `docs/data/` очищенные CSV с метаданными, ссылками, короткими доказательными резюме и результатами разметки.

Текущие локальные источники находятся вне этой папки:

```text
..\files_for_project\литрес рецензии.txt
..\files_for_project\кинопоиск реаензии.txt
```
